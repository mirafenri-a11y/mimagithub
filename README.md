# 共創仲間診断

12の質問で、あなたの「共創タイプ」を8種類から診断する Web アプリです。
仲間どうしの**相性チェック**も付いています。

- サーバー不要（HTML / CSS / JavaScript だけ）
- 回答はブラウザの中だけで処理され、どこにも送信されません
- 結果は URL で共有できます

---

## 診断のしくみ

3つの軸で、あなたの持ち場を測ります。

| 軸 | 意味 | 両端 |
|---|---|---|
| **起点** | どこから物事を動かすか | 構想（V） ⇄ 実装（B） |
| **推進** | どうやって前に進めるか | 牽引（D） ⇄ 調律（H） |
| **射程** | どこに力を向けるか | 開放（O） ⇄ 深耕（C） |

組み合わせで 8 タイプになります。

| コード | タイプ | ひとことで言うと |
|---|---|---|
| VDO | 🔆 灯台 | まだ無いものに、最初の旗を立てる人 |
| VDC | 🔥 炉 | ひとつの問いを、燃やし続ける人 |
| VHO | 🌉 橋 | 違う世界どうしを、言葉でつなぐ人 |
| VHC | 💧 泉 | 静かに、本質を掘り当てる人 |
| BDO | ⛵ 船 | 作って、出して、確かめる人 |
| BDC | 🔨 鍛冶 | 手を動かして、質を上げきる人 |
| BHO | 🌱 土壌 | みんなが動ける場を、整えておく人 |
| BHC | ⚓ 錨 | 続くように、静かに支える人 |

相性は「3つの軸のうち、いくつ補いあっているか」で 100 点満点で算出します。
軸がすべて逆なら 100 点（＝役割が完全に分かれる）、まったく同じタイプなら 40 点です。

## 公開する（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を `GitHub Actions` にする（ここを設定しないと公開は失敗します）
3. `main` または `claude/**` ブランチに push すると自動で公開されます
   - それ以外のブランチを試したいときは **Actions タブ → Deploy to GitHub Pages → Run workflow** で、
     ブランチを選んで手動実行してください

公開先 URL:
`https://<ユーザー名>.github.io/<リポジトリ名>/`

---

## 手元で動かす

`index.html` をブラウザで直接開くだけで動きます。
ローカルサーバーで確認したい場合は:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## テスト

診断ロジック（スコア計算・共有コード・相性）にテストがあります。

```bash
npm test
```

Push すると GitHub Actions（`CI`）でも同じテストが走ります。

## ファイル構成

```
index.html            画面の骨組み
assets/style.css      見た目
assets/data.js        設問12問・8タイプの定義（文言を変えるならここ）
assets/logic.js       スコア計算・共有コード・相性ロジック
assets/app.js         画面の制御
test/logic.test.js    ロジックのテスト
.github/workflows/    CI と GitHub Pages への公開
```

### 設問やタイプの文言を変えたいとき

`assets/data.js` だけを編集してください。

- 設問を足すときは `QUESTIONS` に `{ axis, sign, text }` を追加します
  （`sign: +1` は「そう思う」ほど V / D / O 側、`-1` は B / H / C 側に寄ります）
- タイプの説明文は `TYPES` の中を直接書き換えられます

編集後は `npm test` を走らせると、定義の抜けや矛盾を検出できます。
